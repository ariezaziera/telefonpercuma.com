# telefonpercuma.com — Pelan Gerak Kerja Izzati

Panduan interaktif pengurusan **digital marketing & media sosial** untuk Izzati bagi projek **telefonpercuma.com** di bawah **Redzone Global Sdn Bhd**.

## Kandungan

- Countdown tarikh mula rujukan 7 November 2026
- Timeline pelaksanaan
- Skop PIC Izzati: kumpul video daripada klien, editing, content planning, posting, pengurusan kempen yang diluluskan, pemantauan media sosial dan laporan prestasi
- Interactive task tracker (status tugasan, nota, CSV export dan backup)
- Figurine dan elemen UI cartoonish

**Di luar skop Izzati:** jualan, closing sale, komisen, harga, bajet dan urusan kewangan.

## GitHub Pages

Repository ini menggunakan nama tepat `telefonpercuma.com`.

Untuk aktifkan penerbitan pertama kali:

1. Buka **Settings → Pages** repository ini.
2. Di bahagian **Build and deployment**, pilih **Deploy from a branch**.
3. Pilih **Branch: main**, folder **/(root)**, kemudian **Save**.
4. Semak status deployment pada halaman **Pages** atau **Actions**.

**Alamat GitHub Pages (setelah diaktifkan):**

https://ariezaziera.github.io/telefonpercuma.com/

**Sumber utama laman:** `index.html` pada root branch `main`.

> Nota: Data tracker disimpan menggunakan localStorage pada browser/peranti masing-masing, **bukan sync secara live**. Jangan masukkan maklumat peribadi sensitif ke dalam tracker. Repository ini public dan laman Pages juga boleh dilihat umum setelah diaktifkan.
