# telefonpercuma.com — Pelan Gerak Kerja Izzati

Panduan interaktif operasi media sosial, penyuntingan, posting, campaign dan reporting untuk Izzati, dengan Redzone Global Sdn Bhd sebagai klien.

## Publish dengan GitHub Pages

1. Buat repository bernama `telefonpercuma-com` pada akaun `ariezaziera`.
2. Upload `index.html` ke **root** repository pada branch `main`.
3. Buka **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Pilih `main` dan `/(root)` lalu Save.
5. URL jangkaan selepas deployment: `https://ariezaziera.github.io/telefonpercuma-com/`.

> Nota: tracker menyimpan status dan nota dalam localStorage browser peranti, **bukan data bersama secara live**. Site akan menjadi public jika repository Pages public.
